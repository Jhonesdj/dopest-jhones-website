# DOPEST JHONES — Official DJ Website

A responsive personal website created for DOPEST JHONES, a Lagos-based DJ and music professional.

## About the Project

This project was designed to create a professional online presence for a DJ, allowing visitors to discover the brand, listen to mixes, view services and events, and make booking enquiries.

## Features

- Responsive navigation
- Hero section
- DJ profile/about section
- Audiomack music player integration
- DJ services section
- Upcoming events
- Booking form
- Email contact
- Social media links
- Mobile-responsive layout
- Smooth scrolling navigation

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

https://jhonesdj.github.io/dopest-jhones-website

This project demonstrates my ability to create responsive landing pages and websites for artists, DJs, musicians, events and entertainment brands.
